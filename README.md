# Discord-orders-bot

<div align="center">
  <p>This bot is used in <a href="https://www.discord.gg/dssxeqAXjV">CodeMaven</a> discord server</p>
</div>

<div>
  <p>Writen in JavaScript using these 3 main modules (you can install them all using npm):</p>
</div>

* discord.js - `npm install discord.js`
* sapphire.js - `npm install @sapphire/framework`
* commandkit - `npm install commandkit`

# Running the bot
1. Download
2. Open terminal in that project folder and type `echo BOTTOKEN=token >> .env` (change the `token` to your bot's token)
3. Install the modules *(if needed)
